## 测试条件与边界

- 官方主机 `https://picaapi.picacomic.com`，系统 DNS，直接 HTTPS；证书 CA 与 hostname 正常验证，TLSv1.3。未使用代理、关闭证书校验或跟随重定向。
- 使用 APK 提取的签名公式与 headers；同一进程复用随机 32 位 nonce 和独立随机 app-uuid，image-quality 使用 APK 初始值 `medium`。这不是原 APK/真实 Android 设备的运行时抓包。
- 签名时间参考同一 HTTPS 主机返回的 Date，本机时间相差约 1.7 秒；没有修改系统时钟。
- 登录前有一次无凭据 HEAD `/` 连通性/时间探测，返回 HTTP 400。该根路径探测不作为业务接口健康检查；之后三次业务请求均成功。
- 只执行一次登录、两次 GET；没有注册、修改资料、点赞、收藏、评论、签到或登出请求。登录本身可能产生正常服务端会话/登录日志。
- 密码和 Token 未写入脚本或结果文件，Token 仅在测试进程内使用，进程已结束；未保存完整响应、用户资料或 cookies。会话中仍包含用户自己发来的密码，因此建议测试后修改密码，不宣称聊天历史已删除或服务端会话已撤销。
- 未测试漫画内容、全部 42 个方法、Token 过期/刷新、其他线路或验证码/风控等情况。
